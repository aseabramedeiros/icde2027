# Knowledge Modeling for Neuro-Symbolic Decision Support

This repository contains research artifacts and supporting materials associated with the manuscript **"Knowledge Modeling for Neuro-Symbolic Decision Support"**, by Antony Seabra, Daniel Schwabe, and Sergio Lifschitz, prepared for submission to IEEE ICDE 2027.

## Repository Structure

- **`data_sources/`** — Data sources and supporting materials.
- **`evaluation/`** — Experimental evaluation artifacts.
- **`knowledge_models/`** — Knowledge representations and related files.
- **`notebooks/`** — Jupyter notebooks and supporting scripts.
- **`publications/`** — Manuscripts and related academic materials.

## Status

This repository supports ongoing research. Its contents may be updated as the work progresses.
